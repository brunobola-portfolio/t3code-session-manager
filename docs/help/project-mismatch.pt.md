# Projeto diferente: o T3 Code pôs uma conversa noutro sítio

## O que quer dizer

A conversa foi importada, mas para outro projeto que não o do plano, por isso o t3sm indica-a em vez de a dar como
feita.

## Porque acontece

O projeto mudou de nome, de sítio ou foi criado outra vez no T3 Code depois de o plano ser feito.

## O que fazer

1. Vê a conversa no T3 Code: está lá, noutro projeto.
2. Corre `t3sm plan` e `t3sm apply` outra vez: um plano novo vê o T3 Code como ele está agora.
