# Decisões: conversas à espera da tua resposta

## O que quer dizer

Algumas conversas precisam de um sim ou de um não teu antes de o t3sm as trazer para o T3 Code, e o t3sm nunca
adivinha. Enquanto não respondes, esperam; tudo o resto é importado como de costume.

## Porque acontece

O t3sm pergunta sobre:

- conversas começadas na tua pasta pessoal, ou numa pasta que o T3 Code recusa abrir;
- conversas em pastas temporárias ou do sistema;
- conversas automáticas (começadas pelo Agent SDK);
- conversas que apagaste no T3 Code.

## O que fazer

- Corre `t3sm start`: faz cada pergunta uma vez, explica as escolhas e guarda as tuas respostas no config.json.
- O `t3sm status` e o `t3sm plan` dizem quantas conversas esperam por cada pergunta.
