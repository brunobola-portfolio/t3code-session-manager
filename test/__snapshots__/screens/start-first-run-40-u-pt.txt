1/11 · Boas-vindas
O t3sm traz as tuas sessões antigas para
o T3 Code como threads que podes
continuar.
Cada uma fica na conta Claude a que
pertence.

╭─ Como funciona ────────────────────╮
│ · 11 passos curtos. Podes parar em │
│   qualquer pergunta.               │
│ · Nada se escreve antes de         │
│   responderes s.                   │
│ · Tudo se pode desfazer.           │
│ · Nenhuma sessão é apagada.        │
╰────────────────────────────────────╯
s sim · n não · ? mais · v voltar ·
q sair · Enter escolhe a maiúscula
Em inglês: t3sm start --lang en
